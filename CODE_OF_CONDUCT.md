# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment, personal attacks,
and sustained disruption are not tolerated.

Report unacceptable behavior privately to the maintainers via
[GitHub Security Advisories](https://github.com/appiaworks/shiguchi/security/advisories/new)
or a direct message to a maintainer. Reports are handled confidentially.
