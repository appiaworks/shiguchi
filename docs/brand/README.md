# Shiguchi brand assets

The mark is a sanpō joint: three beams meeting at one corner, the way one contract meets REST, GraphQL and gRPC.

| File | Use |
|---|---|
| `shiguchi-lockup-horizontal.svg` / `.png` | Default logo: docs site, slides. Light backgrounds. |
| `shiguchi-lockup-horizontal-dark.svg` / `.png` | The same on an ink (`#1C1A17`) background. |
| `shiguchi-lockup-horizontal-plain.svg` / `.png` | Without 仕口, for tight spaces. |
| `shiguchi-lockup-stacked.svg` / `-dark` | The README header, and square-ish spaces: social cards, title slides. |
| `shiguchi-mark.svg`, `shiguchi-mark-512/1024.png` | The mark alone, transparent. |
| `shiguchi-icon.svg`, `icon-192/512.png`, `apple-touch-icon.png` | App and avatar icons on an ink tile. |
| `favicon.svg`, `favicon.ico`, `favicon-16x16/32x32.png`, `site.webmanifest` | Browser favicons. |

The wordmark is Shippori Mincho Bold (SIL OFL), converted to outlines, so the SVGs need no font installed.

Palette: washi `#F4EFE6`, ink `#1C1A17`, vermilion `#C23B22` (`#D9573E` on dark), wood `#E9CF9E` / `#C9995A` / `#8E5D2C`, end grain `#D9573E` / `#B8432D` / `#8F3020`.

Don't recolour, stretch or rotate the mark, and leave clear space at least the height of the 仕口 characters around a lockup.
